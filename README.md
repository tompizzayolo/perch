## GLTF/GLB Viewer

A GLTF/GLB model viewer built with the [Bevy Engine](https://github.com/bevyengine/bevy), originally created to test how 3D models look and behave when rendered in Bevy.

Models can be loaded by dragging and dropping them into the application window. 
Should also support the operating system's `Open with` context menu.

You can run it like normal:

```sh
cargo run
