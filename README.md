# Perch

## GLTF/GLB Viewer

A GLTF/GLB model viewer built with the [Bevy Engine](https://github.com/bevyengine/bevy), originally created to test how 3D models look and behave when rendered in Bevy.

You can open it and drag and drop models into window, should also work with "Open with" context menus
